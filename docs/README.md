# 좀비 아포칼립스: 감염자의 이지선다

## 기능 목록

### 게임 시작

- [ ] 초기 상태 설정 (체력 100, 식량 3, 감염도 10, Day 1, 치료 0, 구조 0)
- [ ] 게임 시작 로그 출력

### 카드 덱

- [x] 카드 6종 데이터 만들기 (이름, 장수, 선택지 효과)
- [ ] 20장 덱 만들고 셔플하기
- [ ] 카드 1장 뽑기
- [ ] 덱이 다 떨어지면 리셔플
- [ ] 남은 카드 수 화면에 표시

### 카드 뽑기

- [ ] 뽑기 버튼 누르면 카드와 선택지 보여주기
- [ ] 뽑기 버튼 숨기기
- [ ] 카드 뽑은 로그 출력

### 선택지 고르기

- [ ] 선택지 누르면 버튼 비활성화 + 로딩 표시
- [ ] 2초 뒤에 결과 반영
- [ ] 선택 로그 출력
- [ ] 하루 처리 순서
  - [ ] 카드 효과 적용
  - [ ] 식량 0인지 확인 (기아)
  - [ ] 식량 1 소비
  - [ ] 감염도 3 증가
  - [ ] 기아였으면 체력 10 감소
- [ ] 기아 로그 출력 (`식량이 없어` 포함)
- [ ] 다음 카드 뽑을 수 있게 되돌리기

### 스탯

- [x] 체력, 식량, 감염도는 0 밑으로 안 내려가게
- [x] 치료 횟수, 구조 포인트 세기
- [ ] 상단 스탯 실시간 표시

### 엔딩

- [ ] 체력 0 이하 → 사망
- [ ] 감염도 100 이상 → 좀비화
- [ ] 치료 5회 → 치료 성공
- [ ] 구조 포인트 3 이상 + Day 10 초과 → 구조 성공
- [ ] Day 15 초과 → 생존 성공
- [ ] 실패 엔딩을 성공 엔딩보다 먼저 확인
- [ ] 포기 버튼 → 포기

### 결과 화면

- [ ] 엔딩, 생존 일수, 최종 체력/식량/감염도 표시
- [ ] 재시작 버튼 누르면 상태랑 로그 초기화
